## 🧪 Generating Mock Showcase Locally

You can generate all showcase mockups offline on your machine with a single command:

```bash
npm run generate:mock
```

This runs `scripts/generate-mock.ts`, which synthesizes rich contribution activity and renders all 17 animated GIFs in `assets/` and root `tree.gif` without making external API calls.
