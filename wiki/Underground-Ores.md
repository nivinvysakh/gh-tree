# 💎 Underground Ore Blocks & Badges

Embedded in the underground dirt layer beneath your tree, 6 distinct Minecraft ore blocks unlock as you hit maintainer, contributor, and productivity milestones.

---

## 🗺️ Ore Slot Placement & Unlock Guide

```
[ Slot 0: Netherite ] [ Slot 1: Gold ] [ Slot 2: Diamond ] [ Slot 3: Emerald ] [ Slot 4: Lapis ] [ Slot 5: Redstone ]
```

| Ore Block | Slot | Unlock Condition | Lore & Achievement |
| :--- | :---: | :--- | :--- |
| **Netherite / Ancient Debris** 🪨 | Slot 0 *(Far-Left)* | **Action Creator Exclusive** (`@nivinvysakh` or `is-owner: true`) | **👑 Creator Badge** — Minecraft's rarest material, awarded exclusively to the author and maintainer of `gh-tree`! |
| **Gold Ore** 🪙 | Slot 1 *(Mid-Left 1)* | • **Current streak ≥ 7 days**, *OR*<br>• **≥ 50 total commits** | **⚡ Streak Dedication** — Milestone for sustained rhythm and week-long consistency. |
| **Diamond Ore** 💎 | Slot 2 *(Mid-Left 2)* | • **≥ 25 total commits**, *OR*<br>• **≥ 1 merged PR** | **💎 Active Contributor** — Milestone for regular code contributions and merged PRs. |
| **Emerald Ore** ❇️ | Slot 3 *(Mid-Right 1)* | • **≥ 100 total commits**, *OR*<br>• Any weekly branch reaching **Level 4** (25+ commits/week) | **🏆 Power Contributor** — Rare milestone awarded for high commit volume and intense development sprints. |
| **Lapis Lazuli Ore** 🔷 | Slot 4 *(Mid-Right 2)* | **Contributed to `nivinvysakh/gh-tree`** (verified via GitHub API or `is-contributor: true`) | **🤝 Official `gh-tree` Contributor Badge** — Special celestial blue ore with pyrite flecks awarded exclusively to developers who have contributed code/PRs to this repository! |
| **Redstone Ore** 🔴 | Slot 5 *(Far-Right)* | • **Merged PRs ≥ 2**, *OR*<br>• **Total PR activity ≥ 3**, *OR*<br>• **Current streak ≥ 14 days** | **⚙️ Engineering & Automation** — Milestone honoring pull request lifecycle, code reviews, and multi-week streaks. |

---

## 🤝 How to Unlock the Lapis Lazuli Ore 🔷

1. Fork **[nivinvysakh/gh-tree](https://github.com/nivinvysakh/gh-tree)**.
2. Submit a Pull Request (fixing a bug, improving documentation, or adding a new pixel mob/biome).
3. Once your PR is merged, GitHub's API recognizes your username as an official contributor!
4. The next time your profile tree workflow runs, the **Lapis Lazuli Ore 🔷** will permanently illuminate beneath your tree!
