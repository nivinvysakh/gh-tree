# Welcome to the gh-tree Wiki! 🌴

**gh-tree** turns your GitHub contributions, commit streaks, and pull requests into living **Minecraft Tree biomes** featuring animated companion pets, leveling milestone chests, underground ores, live weather, and holiday events.
